### • Executive Summary

I am a cybersecurity practitioner, penetration tester, and security tooling engineer with hands-on expertise in **Offensive Security, Digital Forensics & Incident Response (DFIR)**, and **automated threat intelligence**.

My work bridges the gap between deep offensive security research and systems-level development — building custom OSINT platforms, dissecting forensic memory and operating system artifacts, and contributing core networking protocols and detection modules to widely deployed industry security engines like **ProjectDiscovery Nuclei**, **Velocidex Velociraptor**, and **Aqua Security Trivy**.

### • Upstream Open Source Contributions

I actively engineer features, protocol drivers, and forensic parsers for industry-standard security tools:

* **[Velocidex / Velociraptor](https://github.com/Velocidex/velociraptor)**  
  *Authored [`Windows.Forensics.Recall`](https://github.com/Velocidex/velociraptor/pull/5130)* — Engineered a forensic artifact parser for Windows 11 Copilot Recall SQLite databases, extracting captured user actions, app engagements, window titles, and tokenized system telemetry.
* **[ProjectDiscovery / Nuclei & Fastdialer](https://github.com/projectdiscovery/nuclei)**  
  *Protocol & Networking Extensions* — Authored the [`MQTT JavaScript protocol module`](https://github.com/projectdiscovery/nuclei/pull/8075) for Nuclei and routed the [`MSSQL driver through Fastdialer`](https://github.com/projectdiscovery/nuclei/pull/8082) with network access policy enforcement and context cancellation propagation.
* **[Aqua Security / Trivy](https://github.com/aquasecurity/trivy)**  
  *Cryptographic Assurance* — Implemented [`weak MD5 certificate signature detection`](https://github.com/aquasecurity/trivy/pull/11543) in Trivy to flag deprecated cryptographic signing algorithms during container and supply-chain audits.
